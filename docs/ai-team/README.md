## Rules

- All AI Employees **must** read and update the Task Board before claiming or handing off work.
- Non-trivial work starts in **`DISCUSS`** (challenge required).
- **No** Claude Code / implementation before CEO **proposal** approval.
- After code: **QA → Security → Reviewer → CEO ship**.
- Role definitions: [`.cursor-ai/`](../.cursor-ai/README.md)
